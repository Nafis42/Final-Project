## 4. Key Empirical Findings and the "Triple Paradox"

All empirical findings are derived from audited 26-year administrative time series (FY98–FY24) harmonized from MoPNG, PPAC, DGCI&S, and RBI records:

```
+----------------------------------------------------------------------------------------------------+
|                               THE "TRIPLE PARADOX" OF INDIA'S PETROLEUM SECTOR                     |
+----------------------------------------------------------------------------------------------------+
|                                                                                                    |
|  1. UPSTREAM STAGNATION VS. DOWNSTREAM GIANT (THE DECOUPLING PARADOX)                              |
|     * Domestic extraction flatlined in a 32-38 MMT corridor for 26 years (CAGR -0.44%).           |
|     * Refining throughput surged +281.6% (68.54 to 261.55 MMT; CAGR +5.57%).                       |
|     * Crude imports surged from 39.81 to 234.26 MMT (CAGR +7.37%); import dependency hit 88.86%.   |
|     * Statistical correlation between domestic extraction and crude imports is zero (r = 0.096).    |
|     * Throughput pulls crude imports with near-unitary elasticity (beta = 1.011, R2 = 0.998).      |
|                                                                                                    |
|  2. AGGREGATE REFINING SURPLUS VS. STRUCTURAL CLEAN COOKING DEFICIT                                |
|     * India has maintained an uninterrupted net product export surplus every year since FY02       |
|       (+13.89 MMT in FY24; peak +43.08 MMT in FY14).                                               |
|     * Giant export surpluses in Diesel (+28.16 MMT) and Petrol (+12.76 MMT).                       |
|     * Concurrently, LPG suffered a -17.99 MMT deficit (62.74% imported) due to PMUY clean cooking  |
|       surge (+488.5%) meeting rigid refinery chemical yield limits (~4.8%).                        |
|     * Subsidized PDS kerosene collapsed by -95.5% (11.38 to 0.51 MMT).                             |
|                                                                                                    |
|  3. PHYSICAL INELASTICITY VS. COMPOUNDING FINANCIAL EXPOSURE                                       |
|     * Physical crude imports grew 5.9-fold; USD bill grew 37.9-fold ($3.52B to $133.37B);          |
|       INR import bill exploded 74.1-fold (Rs. 14,917 Cr to Rs. 1,105,176 Cr).                     |
|     * Price volatility drives 72.3% of annual import bill variation (r = 0.917).                   |
|     * The INR/USD exchange rate depreciated from 42.40 to 82.87 (+3.18% p.a.), adding an           |
|       unhedged compounding wedge that doubled the domestic fiscal burden.                          |
|     * LMDI-I decomposition proves monetary drivers (Price 41.1% + Currency 29.0% = 70.1%)          |
|       overwhelmingly dominate physical volume growth (29.8%).                                      |
|                                                                                                    |
+----------------------------------------------------------------------------------------------------+
```
